01 / CREDENTIALS

添加登录凭据

在 WorkBuddy / CodeBuddy 桌面客户端登录后，按 Win + R 打开以下目录：

%LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth

将其中的 .info 文件拖入“添加账号”，或粘贴其 JSON 内容。后台不提供独立 OAuth 登录，支持保留多个账号并手动切换。
